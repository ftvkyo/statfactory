Version: 0.0.5
Date: 2026-09-12
  Bugfixes:
    - Fix a crash ("attempt to index field 'current_research' (a nil value)") on every save that
      was started before 0.0.4 added storage.current_research — that field was only backfilled on
      on_init, which never re-runs for an existing save. Now also backfilled via
      on_configuration_changed, which does.
---------------------------------------------------------------------------------------------------
Version: 0.0.4
Date: 2026-09-12
  Features:
    - Track research progress and the currently active technology per force.
  Changes:
    - Refresh pollution, evolution, kills, and production every second instead of every 10 seconds,
      matching the export interval — only the area_paved drift correction stays on its own (5 minute)
      timer, since it recounts tiles across the whole surface.
---------------------------------------------------------------------------------------------------
Version: 0.0.3
Date: 2026-09-05
  Features:
    - Track item and fluid production/consumption per surface and force.
  Bugfixes:
    - Correct area_paved drift caused by nukes/reactor explosions destroying tiles outside the
      normal built/mined tile events.
    - Populate player count gauges immediately on init instead of waiting for the first join/leave
      event.
    - Fix misleading/incorrect assert messages in the Prometheus library.
  Changes:
    - Update to Factorio 2.1.
